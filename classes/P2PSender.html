    Class P2PSender

    Sends a single file of any size to a P2PReceiver over a WebRTC data channel, end-to-end encrypted with a seed the server never sees.

    The session outlives a single peer: if the channel dies or a joiner cannot prove it holds the seed, the sender drops that peer and waits for the next one, which lets a receiver re-join and resume from its validated offset. Memory stays bounded — one chunk is read through getBytes at a time and sending pauses whenever the channel's send buffer fills up.
